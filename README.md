# Система управления инвентаризацией автозапчастей

## 1. Введение

**Назначение:** консольное приложение для складского учёта автозапчастей. Позволяет отслеживать остатки, проводить приёмку и списание, выполнять инвентаризацию и получать отчёты.

**Целевая аудитория:** сотрудники склада (кладовщики), администраторы, а также менеджеры, которым нужен доступ к остаткам без права редактирования.

---

## 2. Начало работы

### Установка

```bash
pip install werkzeug pytest
```

### Запуск

```bash
python3 main.py
```

### Регистрация

При первом запуске выберите `2. Зарегистрироваться` и введите:

```
Логин: ivanov
Пароль: mypassword
Роль: admin
```

Доступные роли:

| Роль        | Что может делать                                      |
|-------------|-------------------------------------------------------|
| `admin`     | Всё: добавление, удаление, приёмка, списание, отчёты |
| `warehouse` | Приёмка, списание, добавление товаров, инвентаризация |
| `viewer`    | Только просмотр товаров и отчётов                    |

### Вход в систему

Выберите `1. Войти`, введите логин и пароль. После входа откроется главное меню с функциями, доступными вашей роли.

## 3. Основной функционал

### Добавить товар (пункт 6)

Доступно: `admin`, `warehouse`

```
Название: Фильтр масляный Mann W712
Артикул (SKU): MANN-W712
Категория: Фильтры
Количество: 30
Минимальный остаток: 5
```

### Приёмка товара (пункт 7)

Увеличивает остаток при поступлении новой партии.

```
Артикул (SKU): MANN-W712
Количество: 20
→ Приёмка: +20 шт. 'Фильтр масляный Mann W712'. Остаток: 50
```

### Списание товара (пункт 8)

Уменьшает остаток при выдаче или расходе.

```
Артикул (SKU): MANN-W712
Количество: 5
→ Списание: -5 шт. 'Фильтр масляный Mann W712'. Остаток: 45
```

### Инвентаризация (пункт 9)

Сверяет фактический остаток с учётным и исправляет расхождение.

```
Артикул (SKU): MANN-W712
Фактическое количество: 42

-- Инвентаризация: Фильтр масляный Mann W712 --
  По учёту:    45 шт.
  Фактически:  42 шт.
  Недостача: -3 шт. — обновляем остаток.
```

### Поиск по названию (пункт 3)

Доступно всем авторизованным пользователям. Ищет по части слова.

```
Введите название для поиска: фильтр
→ Результаты поиска 'фильтр': 3 шт.
```

### Карточка товара (пункт 4)

Показывает полную информацию по артикулу.

```
Введите артикул (SKU): MANN-W712

========================================
  Карточка товара
========================================
  Название:     Фильтр масляный Mann W712
  Артикул:      MANN-W712
  Категория:    Фильтры
  Остаток:      42 шт.
  Мин. остаток: 5 шт.
  Статус:       В норме
========================================
```

### Товары с низким остатком (пункт 2)

Показывает все позиции, у которых остаток упал ниже минимального.

### Отчёт по складу (пункт 5)

Сводная статистика: количество позиций, общее число единиц, сколько позиций заканчивается, разбивка по категориям.

### Удалить товар (пункт 10)

Доступно только `admin`. Полностью удаляет позицию из системы по артикулу.

## 4. Дополнительно

### Управление пользователями

Регистрацию новых сотрудников выполняет администратор вручную при запуске приложения. Каждый пользователь имеет логин, хешированный пароль и роль.

### Безопасность

- Пароли хранятся в хешированном виде (pbkdf2:sha256), в открытом виде нигде не сохраняются.
- Без авторизации доступ к любым данным закрыт.
- Каждая операция проверяет роль пользователя — при недостатке прав выводится ошибка 403.

### Категории запчастей

Рекомендуемые категории для удобной фильтрации:
`Двигатель`, `Тормоза`, `Фильтры`, `Подвеска`, `Электрика`, `Кузов`, `Трансмиссия`

## 5. Частые вопросы (FAQ)

**Как изменить пароль?**
В текущей версии — перерегистрация с новым паролем (старый аккаунт удаляется вручную администратором из словаря `auth.users`).

**Как удалить товар?**
Войдите под ролью `admin`, выберите пункт `10. Удалить товар` и введите артикул (SKU).

**Что делать если забыл артикул?**
Используйте пункт `3. Поиск по названию` — достаточно ввести часть слова.

**Почему не вижу пункты меню для добавления товаров?**
Эти функции доступны только ролям `admin` и `warehouse`. Если вы зарегистрированы как `viewer` — обратитесь к администратору для смены роли.

**Данные сохраняются после закрытия?**
В текущей версии данные хранятся в памяти и сбрасываются при перезапуске. Для постоянного хранения потребуется подключение базы данных.
