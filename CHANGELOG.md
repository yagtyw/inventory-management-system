# Changelog - Система управления инвентаризацией

## [1.1.0] 

### Добавлено
- Модуль уведомлений с классом Notification
- Метод `remove_item` для удаления товара из системы
- Метод `get_all_items` для получения списка всех товаров
- Метод `get_total_count` для подсчета количества товаров
- Проверка на дубликаты при добавлении товара
- Вспомогательный метод `_validate_amount` для проверки количества

### Исправлено
- Устранено дублирование кода
- Добавлена документация ко всем методам (docstrings)
- Магическое число 5 заменено на константу DEFAULT_LOW_STOCK_THRESHOLD
- Поле items сделано приватным (_items)

### Тесты
- Добавлено 9 новых тестов
- Проверка граничных случаев (отрицательное количество, списание большего)

## [1.0.0] 

### Добавлено
- Базовый класс InventoryItem для управления товаром
- Класс InventoryManager для управления множеством товаров
- Методы add_stock, remove_stock, is_low_stock
- CI/CD настройки с GitHub Actions
- Flake8 для проверки стиля кода
